# تحویل طراحی و موارد باز

## مسئله و شواهد

کاربر پس از کامیت نسخه جاری، صریحاً «آماده‌سازی تحویل طراحی و فهرست موارد باز» را انتخاب کرد. منابع: README، REFERENCE_STYLE، PATTERNS، مشخصات M7 و هماهنگی پنل، USABILITY_TEST، کامیت‌های d629368/638c39f/f03c3a2 و ZIP سیستم طراحی. ZIP موجود ۱۵فایل دارد و محتوای آن با پوشه منبع برابر است؛ ساختار تحویل یکپارچه پنل و موارد باز هنوز یک سند مرکزی ندارد. PROJECT_MAP/docs/README/graph در اپ مستقل موجود نیست؛ workflow سبک استفاده می‌شود. کار فقط مستندات/بسته محلی است؛ مرورگر یا کد محصول/توکن/API/مجوز تغییر نمی‌کند.

## الزامات و پذیرش

- R1 / AC1: سند مرکزی شامل نقاط ورود کاتالوگ/وایرفریم/پنل، منابع معتبر توکن و UI، رفتارهای قطعی، وضعیت داده mock، شواهد نسخه فعلی و محدودیت‌های اعتبارسنجی باشد. نسخه تاریخی از قاعده جاری تفکیک شود.
- R2 / AC2: موارد باز با شناسه، اثر، نقش مسئول پیشنهادی، تصمیم موردنیاز و معیار بسته‌شدن ثبت شوند؛ آزمون انسانی انجام‌شده یا تأیید محصول نهایی ادعا نشود. ورود/فایل/ذخیره/مجوز و سرویس واقعی صرفاً موارد بازند، نه قرارداد API تازه.
- R3 / AC3: ZIP تحویل بازتولیدپذیر و محلی شامل راهنما، آزمون انسانی، توکن/کتابخانه مرجع، مشخصات و تصاویر منتخب، همراه manifest مسیر/اندازه/SHA256 و revision منبع باشد. بسته سورس کامل اپ اجرایی یا انتشار نیست؛ فقط whitelist فایل‌های تحویل، بدون env/node_modules/log یا اطلاعات حساب. لینک‌های سند مرکزی و تطابق bytes و checksum همه اعضای بسته بررسی شود.
- R4 / AC4: README و نمایه به راهنما اشاره کنند؛ فرمان بسته‌سازی و بررسی موفق ثبت و Git diff check انجام شود. تست/lint/build محصول از آخرین اجرای موفق 638c39f ارجاع داده شوند؛ برای کار صرفاً مستندات مجدداً اجرا نشوند.

## مرز و اجرا

script از Python standard library و فایل‌های موجود استفاده کند؛ dependency/interface/مدل جدید لازم نیست. واردات بلااستفاده و فایل‌های خارج whitelist بسته نشوند. rollback با فایل‌های این مرحله؛ source و دارایی‌های موجود حفظ شوند. UNKNOWN: نتایج کاربران هدف، ممیزی انسانی صفحه‌خوان/zoom و قرارداد سرویس واقعی.

- [x] W1 (complete): راهنمای مرکزی/موارد باز و script بسته‌سازی. (AC1–AC3) — مسیرها/قواعد جاری/۹مورد باز و whitelist بسته ساخته شد؛ تولید اولیه۸۰فایل و لینک‌های سند مرکزی و checksum موفق.
- [x] W2 (complete): تولید/بررسی ZIP، مستندات/نمایه و ثبت تحویل. (AC3/AC4)
