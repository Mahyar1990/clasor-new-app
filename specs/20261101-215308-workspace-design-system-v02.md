# هماهنگی UI پنل

## مسئله و شواهد

کاربر پس از به‌روزرسانی وایرفریم‌ها خواست مرحله هماهنگ‌سازی پنل اصلی انجام شود. مرجع `lib/design-system/REFERENCE_STYLE.md` و تم/توکن‌های جاری ۰٫۲ است: بوم بیرونی خنثی، سطح سفید، شعاع قاب/کارت/دیالوگ/کنترل برابر ۲۴/۱۶/۲۰/۸، کنترل ۳۶ و لمس ۴۴. workspace.css هنوز قاب تمام‌صفحه بدون بوم بیرونی، شعاع کارت ۱۰/۱۲، سایه‌های قدیمی و وزن عنوان ۶۵۰/۷۰۰ دارد. ترکیب shell، portalهای فرم/اطلاعات/تأیید و reader/نسخه/اشتراک بررسی شدند. راهنمای Next use-client خوانده شد. PROJECT_MAP/docs/README/graph در اپ مستقل موجود نیست؛ README/مشخصات قبلی و source مبنا هستند.

تغییرهای قبلی سیستم طراحی و وایرفریم در working tree حفظ شوند؛ فایل sample.webp و دارایی‌های کارهای دیگر دست نخورند. این کار صریحاً UI است، API/وابستگی/مجوز/ذخیره‌سازی تغییر نمی‌کند.

## الزامات و پذیرش

- R1 / AC1: قاب پنل روی بوم بیرونی خنثی با لبه سفید و شعاع ۲۴، ناوبری و نوار بالا هماهنگ با وایرفریم ۰٫۲؛ sticky ناوبری در قاب کار کند. اسناد من/اشتراکی/مخزن/پوشه/مطالعه از همان سطوح استفاده کنند.
- R2 / AC2: کارت و فهرست و reader و همکاری/نسخه‌ها شعاع ۱۶ و سایه مشترک ملایم، عنوان کارت ۱۵ با وزن متوسط و عنوان صفحه حدود ۲۸ داشته باشند. فرم معمولی ۵۲۰ و شعاع۲۰، تأیید۴۰۰ و شعاع۲۰؛ کنترل‌ها۳۶ و لمس۴۴. ورودی و focus قابل تشخیص؛ متن مطالعه خوانا و بدون کوچک‌سازی کلی.
- R3 / AC3: ایجاد مقصد ثابت، ویرایش/انتقال/حذف/تأیید، تب‌ها و پنل اطلاعات کار کنند؛ بارگذاری خودکار با skeleton و حفظ انتخاب/focus/scroll، فیلتر/جست‌وجو و بازگشت زمینه حفظ شوند. رفتار منطقی این مسیرها بازنویسی نشود.
- R4 / AC4: بررسی مرورگر در۱۴۴۰/۷۶۸/۳۶۰ بدون سرریز، اندازه‌های فرم/لمس، navigation/Escape، حالت skeleton و پایان فهرست؛ ۲۳ تست موجود، lint/build و diff check. README، مشخصات و نمایه و شواهد محلی به‌روز شوند.

## مدل، مرزها و ریسک

قاب بیرونی کلاس ws-canvas و همان grid ws-app؛ CSS پنل و portalهای ws-* مالک ظاهرند. interface یا مدل تازه لازم نیست. CSS قدیمی متناقض اصلاح شود؛ واردات تکراری/بلااستفاده بررسی شوند. توکن‌های جاری مصرف شوند و source/reference-style و globalها تغییر نکنند. rollback با فایل‌های همین کار ممکن است. UNKNOWN: آزمون انسانی صفحه‌خوان، لمس فیزیکی و سایر مرورگرها؛ نمونه موقت است و reload داده را reset می‌کند.
