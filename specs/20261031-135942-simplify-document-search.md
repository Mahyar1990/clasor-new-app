# اصلاح نوار جست‌وجو

ادامه طراحی [اسناد من](20261030-200047-personal-documents.md). کاربر شلوغی گزینه‌های ناحیه جست‌وجو را گزارش کرده است. اکنون سه Select و ورودی جست‌وجو در قاب دو ردیفی دیده می‌شوند.

## الزام‌ها و معیار پذیرش

- R1 / AC1: در ابتدا فقط جست‌وجوی نام و دکمه فیلترها در ناحیه جست‌وجو دیده شوند؛ نوع/وضعیت در تمام اندازه‌ها بسته باشند و با دکمه نام‌دار و aria-expanded باز شوند.
- R2 / AC2: مرتب‌سازی به منوی کوچک بالای نتایج منتقل شود؛ مقدار جاری و گزینه انتخاب‌شده روشن و رفتار قبلی حفظ شود.
- R3 / AC3: فیلترهای فعال هنگام بستن پنل قابل مشاهده و قابل حذف جداگانه باشند؛ حذف فیلتر نوع/وضعیت عبارت جست‌وجو را پاک نکند.
- R4 / AC4: نمایش ۳۶۰ و ۱۴۴۰ بدون سرریز؛ فیلتر، حذف و مرتب‌سازی در مرورگر بررسی؛ lint و build موفق.

## محدوده

تغییر در personal-documents.tsx و workspace.css؛ اجزای فعلی Button، SelectField و DropdownMenu مصرف شوند. منطق داده و صفحه‌بندی/انتخاب عوض نمی‌شود؛ API و dependency و interface تازه ندارد. تست تازه برای جابه‌جایی بصری اضافه نمی‌شود؛ بررسی مرورگر متناسب است. ریسک اصلی پنهان‌ماندن فیلتر فعال است که با chip و شمارنده برطرف می‌شود؛ برگشت با بازگرداندن تغییر همین دو فایل است.

## نتیجه

AC1: پنل در شروع در دسکتاپ و موبایل بسته است؛ فقط جست‌وجو و دکمه فیلترها در قاب دیده می‌شوند. ارتفاع قاب بسته در دسکتاپ ۱۰۴ پیکسل ثبت شد.

AC2: منوی مرتب‌سازی گزینه انتخاب‌شده را نشان می‌دهد؛ انتخاب قدیمی‌ترین، گزارش ماهانه را در نتایج جست‌وجوی «گزارش» ابتدا قرار داد. پس از انتخاب، منو با closeOnClick بسته می‌شود.

AC3: PDF روی نتایج «گزارش» چهار سند برگرداند؛ پس از بستن پنل برچسب PDF باقی ماند و حذف آن عبارت «گزارش» را حفظ کرد.

AC4: در عرض‌های ۳۶۰ و ۱۴۴۰ عرض سند به‌ترتیب ۳۴۵ و ۱۴۲۵ بود؛ بازوبسته‌شدن پنل در موبایل بررسی شد. npm run lint و npm run build شامل TypeScript و ۸۵ توکن موفق شدند. [تصویر دسکتاپ](../.codex/qa-simplify-search/desktop.png) و [تصویر موبایل](../.codex/qa-simplify-search/mobile.png) ثبت شدند.

اتصال مرورگر در ابتدا خطای session داشت؛ با بازنشانی اتصال ابزار رفع شد. این اشکال مربوط به کد برنامه یا Next.js نبود. آزمون انسانی صفحه‌خوان در این اصلاح انجام نشده است.
