# سیستم طراحی کلاسور — نسخه ۰.۳

مرجع اجرایی، کامپوننت‌های React در components/ui و کاتالوگ زنده در مسیر / است. صفحه‌های /workspace و /wireframes از همین مبانی استفاده می‌کنند. پوشه HTML مستقل بازنشسته شده است.

توکن‌های اصلی در lib/design-system/tokens.json و قراردادها در components.json همین پوشه هستند. CSS را با npm run tokens:generate تولید و با npm run tokens:check بررسی کنید. فونت‌های محلی برنامه در app/design-assets حفظ شده‌اند.

قرارداد جاری پس از Master Refactor در `d124673`: تمام قاب‌ها و کارت‌های اصلی، هدر، سایدبار و پنجره‌ها شیشه‌ای‌اند. قاب SolidForm/SolidDataTable نیز شیشه‌ای است؛ فقط ردیف‌های داخلی داده می‌توانند برای خوانایی مات بمانند. `GlassCard` سطح مشترک، `AppLayout` قالب اصلی و `classes.ts` مالک قراردادهای Tailwind ظاهر و حالت‌ها هستند؛ CSS متریال به Tailwind منتقل و حذف شده است. بنفش، فونت IRANYekan، RTL و رفتارهای مجوز، نسخه، تأیید و بارگذاری فهرست حفظ شده‌اند.

هر فایل React حداکثر ۲۰۰ خط فیزیکی است؛ کانتینر و کنترل/لینک شناسه تست صریح دارد. از ویژگی‌های منطقی RTL، گوشهٔ lg/xl، Select شادسن Base UI، حالت‌های پیش‌فرض قابل تشخیص و Hover نیمه‌شفاف استفاده کنید. Select بومی، هاور سفیدِ مات و override متناقض برای یک مسیر مجاز نیستند. ورودی‌های عمومی فایل‌های تقسیم‌شده حفظ می‌شوند.

راهنمای شروع بازیابی دانش [docs/RAG.md](../../docs/RAG.md) است؛ [AGENTS.md](../../AGENTS.md) قواعد مهندسی را تعیین می‌کند. `ui:check`، `lint` و `build` پیش از تحویل اجرا می‌شوند. نتیجهٔ ثبت‌شده و حدود اعتبار در [VALIDATION.md](VALIDATION.md) آمده است؛ گزارش تاریخی را نتیجهٔ آزمون جدید فرض نکنید.

در کاتالوگ و فضای کار از «نمای سطح» برای انتخاب شیشه مات یا بدون شفافیت استفاده کنید. تنظیم در نشست برنامه برقرار است و به منوهای پورتال هم اعمال می‌شود. قواعد fallback و پوشش تمام کامپوننت‌ها در MATERIALS.md آمده است.

validation.json شواهد تاریخی کاتالوگ مستقل است؛ پذیرش کامل دسترس‌پذیری یا اندازه‌گیری کنتراست برنامه React محسوب نمی‌شود. بررسی‌های مهاجرت در مشخصات ویژگی ثبت می‌شوند.

کاتالوگ ۱۴ بخش با صفحه‌های مستقل دارد: `/` برای رنگ و هویت و `/design-system/[section]` برای سایر بخش‌ها. چیدمان و کنترل‌های شیشه‌ای در `/design-system/layout` است. فهرست مشترک مسیرها و منو در `components/design-system/catalogue-sections.ts` قرار دارد؛ هر صفحه فقط نمونه‌های همان بخش را رندر می‌کند.
