## مرجع بصری جاری — ۲۰۲۶/۱۱/۱۴

تصمیم‌های جدید Glass بر برداشت تصویری نسخهٔ ۰.۲ اولویت دارند. مرجع زنده `/` و قرارداد [MATERIALS.md](MATERIALS.md) است: قاب‌ها tint/30 و blur/12px، شعاع حداکثر ۱۶px، فیلد پیش‌فرض قابل تشخیص، دکمه ثانویه دارای سایه و Hover منو نیمه‌شفاف است.

هندسهٔ مرجع به کلاس‌های Tailwind در `components/design-system/catalogue-layout.ts` منتقل شده و فقط روی ریشهٔ کاتالوگ مصرف می‌شود. سیاست مواد و حالت‌ها در `classes.ts` است؛ stylesheetهای قدیمی مرجع/متریال حذف شده‌اند. برای اصلاح ظاهر، روی کلاس و مالک مشترک کار کنید؛ هیچ برداشت از تصویر قدیمی، مجوز بازگرداندن فرم/قاب Solid یا شعاع ۲۰/۲۴px نیست.

# الگوی بصری برگرفته از تصویر مرجع

نسخه ۰.۲ — ۲۰۲۶/۱۰/۳۱

مرجع این بازنگری `sample.webp` است. سفید، خاکستری خنثی و بنفش روشن از ناحیه‌های پرتکرار تصویر نمونه‌برداری شده‌اند؛ اندازه‌ها برداشت بصری‌اند و ادعای استخراج از فایل طراحی اصلی ندارند. زبان فارسی، جهت RTL، فونت محلی و رفتار کامپوننت‌ها حفظ شده‌اند.

کارت‌ها با حاشیه بسیار کم‌رنگ و سایه ملایم از بوم جدا می‌شوند. عنوان کارت ۱۵ و عنوان بخش ۲۰ پیکسل است؛ وزن متوسط جای تأکیدهای ضخیم را در عنوان‌های کوتاه گرفته است. عنوان معرفی ۳۲ و در موبایل ۲۸ پیکسل است. مقیاس عمومی متن فارسی حفظ شده؛ ارتفاع خط بدنه ۱٫۸ و عنوان/برچسب ۱٫۵ است.

بنفش ۶۰۰ برای متن سفید کوچک کنتراست کافی ندارد؛ بنابراین رنگ برند و توکن action.primary عمداً دو مقدار متفاوت‌اند. تأیید، نوع دسترسی و آخرین نسخه همچنان معناهای مستقل دارند. هیچ نمودار، تقویم، صفحه مدیریت نیروی انسانی یا محتوای کسب‌وکار تصویر به محصول اضافه نشده است.

منبع توکن‌ها `lib/design-system/tokens.json` است. CSS متغیرهای توکن با `npm run tokens:generate` تولید می‌شود. چیدمان اختصاصی کاتالوگ در `components/design-system/catalogue-layout.ts` با کلاس‌های Tailwind به `.clasor` محدود است؛ رنگ‌ها، اندازه‌ها و نگاشت‌های عمومی از تم مشترک مصرف می‌شوند. بنابراین صفحات موجود پنل نیز رنگ‌ها و شعاع‌های مشترک تازه را به ارث می‌برند؛ رفتار و بارگذاری فهرست‌ها تغییر نکرده است.

نسخه HTML چندفایلی و مستقل نیز در `clasor-design-system` بازسازی شده‌اند. نسخه React با مرورگر بازبینی شده؛ ادعای بازبینی جداگانه بصری خروجی HTML مستقل وجود ندارد.
