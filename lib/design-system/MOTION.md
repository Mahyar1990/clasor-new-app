# حرکت و انیمیشن رابط کلاسور

مرجع پیاده‌سازی این سند `920c5e4` است. قراردادها در [classes.ts](classes.ts) و مدت‌ها در [tokens.json](tokens.json) تعریف می‌شوند.

| تعامل | حرکت و مدت | مصرف‌کننده |
| --- | --- | --- |
| هاور و فشردن دکمهٔ فعال | جابه‌جایی عمودی ۲ پیکسل، ۱۲۰ms | Button و glass.interaction |
| منو، زیرمنو و Select | شفافیت، ۱۲۰ms | DropdownMenu و Select |
| Dialog و AlertDialog عمومی | شفافیت، ۱۸۰ms | پایه‌های dialog و alert-dialog |
| پنل موبایل | جابه‌جایی از لبه و شفافیت، ۱۸۰ms | Sheet |
| پیام گذرا | جابه‌جایی و شفافیت، ۱۸۰ms | Toast |
| تب | رنگ زمینه، ۱۲۰ms | ClasorTabs |
| شاخهٔ سازمان | چرخش فلش، ۱۲۰ms | HierarchyList |
| پیشرفت بارگذاری | مقیاس افقی بخش نمایشی، ۱۲۰ms | ProgressIndicator و UploadProgress |
| سایدبار دسکتاپ پابلیش | جابه‌جایی افقی ۱۲ پیکسل و شفافیت، ۱۸۰ms | ResizablePane با open |
| فهرست سند پابلیش و گزینه‌های شناور | جابه‌جایی عمودی ۸ پیکسل و شفافیت، ۱۸۰ms | DockedPanel با animate و FloatingActionBar |

Base UI برای بازشدن فوری منو ممکن است `data-instant` بدهد. قرارداد منو در این حالت گذار را حذف می‌کند. Skeletonها ثابت هستند. محتوای تب، شاخه‌های OutlineNavigation و بازشدن جستجوی اسناد در پیاده‌سازی فعلی بی‌درنگ تغییر می‌کنند.

## چرخهٔ پنل‌های پابلیش

[AnimatedDisclosure](../../components/ui/AnimatedDisclosure.tsx) از Collapsible در Base UI استفاده می‌کند. `keepMounted` وضعیت و اسکرول فرزندان را نگه می‌دارد. هنگام بستن، پنل فوراً inert می‌شود و تا پایان گذار در چیدمان می‌ماند. سپس فضای آن آزاد می‌شود. وضعیت‌های starting و ending را Base UI مدیریت می‌کند.

تغییر عرض سایدبار با کشیدن یا صفحه‌کلید مستقل از حرکت باز و بسته‌شدن است. عرض در بازکردن دوباره حفظ می‌شود. عرض، ارتفاع، blur و سایه در این انیمیشن‌ها گذار ندارند.

دکمهٔ بستن داخل سربرگ سایدبار کنار نام مخزن است. با بستن، فوکوس به دکمهٔ بازکردن در همان ستون می‌رود. با بازکردن دوباره، فوکوس به دکمهٔ بستن منتقل می‌شود. Sheet موبایل از مدیریت فوکوس و بستن Base UI استفاده می‌کند.

بستن فهرست سند، فوکوس را به دکمهٔ فهرست برمی‌گرداند. اگر گزینه‌های شناور جمع شده باشند، دکمهٔ اصلی نوار شناور مقصد فوکوس است.

## کاهش حرکت و کارایی

حرکت‌ها از `motion-safe` استفاده می‌کنند. با فعال‌شدن `prefers-reduced-motion: reduce`، تغییر وضعیت پنل‌ها فوری است. فهرست‌ها همچنان با دسته‌های ده‌تایی بارگذاری می‌شوند. حرکت جداگانه برای تک‌تک ردیف‌ها تعریف نشده است.

این طراحی از گذارهای کوتاه شفافیت و جابه‌جایی استفاده می‌کند. سنجش نرخ فریم روی دستگاه ضعیف در شواهد فعلی ثبت نشده است.

## نمونه‌ها و بررسی

نمونهٔ کامل خوانشگر در [ناوبری](/design-system/navigation#clasor-publish-pattern) و نمونهٔ مستقل ابزارها در [ابزارهای پابلیش](/design-system/navigation#publish-tools-catalogue) قرار دارند.

در Firefox، باز و بسته‌شدن سایدبار، فهرست سند و نوار شناور را در عرض‌های دسکتاپ و موبایل بررسی کنید. هنگام خروج، پنل باید تا پایان محوشدن دیده شود و کنترل‌های آن از دسترس فوکوس خارج شوند. پس از پایان، محتوا فضای آزادشده را بگیرد. همین مسیر را با کاهش حرکت، تم تاریک و تغییر سریع وضعیت تکرار کنید.

## مورد باقی‌مانده

`GlassModal` ترکیبی و `NavigableGlassModal` مصرف‌کنندهٔ آن هنوز `glass.dialogMotion` را روی Popup اعمال نمی‌کنند. دیالوگ‌های حساب، جستجو و فرم‌های محصول که از این ترکیب استفاده می‌کنند، گذار دیالوگ عمومی را دریافت نمی‌کنند. اصلاح حرکت پنل‌های پابلیش این مورد را پوشش نداده است. شواهد مرتبط با revision در [VALIDATION.md](VALIDATION.md) ثبت شده‌اند.
