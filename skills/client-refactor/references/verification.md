# راستی‌آزمایی ریفکتور

معیار تحویل را به رفتار قابل مشاهده وصل کن. برای هر مسیر تغییرکرده، از route مستقیم یا مسیر ناوبری معمول وارد شو و عمل اصلی را انجام بده. حفظ URL، handler، داده، validation، خطا و مجوز را در موارد مربوط بررسی کن.

| ناحیه | بررسی لازم در صورت تغییر |
| --- | --- |
| پوسته و ناوبری | RTL/LTR متناسب با محصول، موبایل، اسکرول مستقل، عدم سرریز، لینک مستقیم و بازگشت |
| کنترل و فرم | focus، label، مقدار، خطا، disabled و loading، ارسال یک‌باره و retry |
| overlay | menu/submenu، portal، ترتیب لایه، Tab، Escape و بازگشت فوکوس |
| تم | روشن/تاریک/سیستم، تغییر از UI واقعی، بستن دیالوگ تنظیم، ناوبری، reload و portal |
| حرکت | ورود و خروج جدا، frame میانی، inert، reduced motion و تغییر سریع وضعیت |
| داده | حفظ رکورد/selection هنگام append، reset/cancel هنگام جستجو و تغییر query |
| محصول | فرم و منو با داده و نقش فعلی، نتیجهٔ درخواست و خطای قابل بازیابی |

موارد موجود در کاتالوگ را در مصرف‌کنندهٔ واقعی نیز اجرا کن. حضور class یا import، فعال‌بودن تعامل را ثابت نمی‌کند. wrapper می‌تواند motion یا test ID را از دست بدهد.

فرمان‌های build/lint/typecheck/test را از مقصد بخوان. برای تغییر رفتاری از suite موجود و مرورگر هدف استفاده کن. تست تازه زمانی لازم است که regression مشخصی را پوشش دهد. خطای شناخته‌شدهٔ baseline را با revision و تفاوت تغییر جاری ثبت کن.

build قابل تحویل را با CSS و assetهای خودش اجرا کن. رنگ معنایی، dark، utilityهای state و motion باید در computed styles مصرف‌کننده وجود داشته باشند. اگر fallback bundler کامپایل شد ولی CSS ناقص بود، نتیجهٔ بصری آن معتبر نیست. نتیجهٔ dev را با برچسب dev ثبت کن.

در گزارش بنویس چه چیزی تغییر کرد، کدام مسیر/state اجرا شد، چه چیزی بررسی‌نشده ماند و blocker دقیق چه بود. گذشتن lint، axe یا تست منطقی به معنی پذیرش انسانی screen reader، کنتراست همهٔ زمینه‌ها یا کارایی روی دستگاه ضعیف نیست. برای ادعای کارایی، ابزار و دستگاه یا شبیه‌سازی و نتیجهٔ اندازه‌گیری را ثبت کن.

تغییر را در دامنهٔ feature review کن و فایل موقت، capture، دادهٔ حساب و artifact تولیدی را از commit خارج نگه دار. مرج و ارسال را فقط با مجوز معتبر کار انجام بده و نتیجهٔ ریموت را پس از ارسال بررسی کن.
