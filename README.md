# سیستم طراحی کلاسور

کتابخانه فارسی، RTL و روشن بر پایه Next.js، React، Tailwind و shadcn/ui با primitiveهای Base UI.

## اجرا

```sh
npm install
npm run dev
```

اجرای پیش‌فرض: [اسناد من روی پورت ۳۰۰۰](http://localhost:3000/workspace/documents).

برای اجرای هم‌زمان با نسخه قدیمی روی پورت ۳۰۰۰:

```sh
npm run dev -- --port 3101
```

صفحه نمونه [اسناد من](http://localhost:3101/workspace/documents) شامل ۳۲ سند شخصی، جست‌وجوی خلوت، فیلتر بازشونده، مرتب‌سازی، بارگذاری خودکار ۱۰تایی، انتخاب موارد نمایان و پنل اطلاعات است. [اشتراکی‌ها](http://localhost:3101/workspace/shared) و [مخزن‌ها](http://localhost:3101/workspace/repositories) نیز قابل مرورند. عنوان سند صفحه مستقل مطالعه را باز می‌کند؛ بازگشت در همان جلسه، تنظیم‌ها و تعداد نمایش‌داده‌شده فهرست را حفظ می‌کند. حالت‌های خالی، بارگذاری و خطا در بخش «درباره این نسخه و حالت‌های نمونه» قابل بررسی‌اند. داده‌ها محلی‌اند و پس از بارگذاری دوباره بازنشانی می‌شوند.

قاعده همه فهرست‌های داده پنل (سند، مخزن، پوشه، نسخه و گیرنده)، بارگذاری خودکار دسته بعدی هنگام رسیدن انتهای فهرست به محدوده دید و افزودن تجمعی است. اسکلت ردیف در بارگذاری اولیه اسناد و هنگام افزودن نشان داده می‌شود؛ تأخیر ۶۰۰ میلی‌ثانیه‌ای صرفاً شبیه‌سازی mock است. انتخاب‌ها، فوکوس و موقعیت اسکرول هنگام افزودن حفظ می‌شوند؛ جست‌وجو، فیلتر و مرتب‌سازی بارگذاری قبلی را لغو و از دسته اول آغاز می‌کنند. فهرست کوتاه کنترل اضافه ندارد و پس از آخرین دسته پیام پایان نشان داده می‌شود. دکمه جایگزین فقط برای مرورگر فاقد IntersectionObserver است.

ایجاد دو مرحله‌ای متن/PDF/تصویر نمونه در محل فعلی، ویرایش متن ساده، تغییر نام، انتقال به پوشه همان مخزن، حذف با تأیید و برگرداندن سند در حافظه نشست فعال‌اند. ویرایش‌های ذخیره‌نشده در رفت‌وبرگشت داخلی حفظ می‌شوند و بستن ویرایشگر نیازمند تعیین تکلیف تغییرات است. هشدار reload با `beforeunload` به رفتار مرورگر وابسته است و تضمین ذخیره نیست. سندهای تازه پس از reload دیگر موجود نیستند و پیام بازگشت دارند. اسناد اشتراکی و مخزن بایگانی در این مرحله فقط خواندنی‌اند. ارسال فایل واقعی و ذخیره پایدار ساخته نشده‌اند.

تب «نسخه‌ها» محتوای ثبت‌شده و مبنای نسخه را نشان می‌دهد؛ هر ذخیره متن متفاوت، نسخه بعدی را با وضعیت پیش‌نویس می‌سازد. سند «راهنمای شروع یک پروژه تازه» سه نسخه ساختگی مرتبط دارد. در تب «تأیید و اشتراک»، درخواست بررسی و شبیه‌سازی تصمیم مدیر (تأیید/رد با دلیل) و مدیریت گیرندگان ساختگی در دسترس‌اند. نتیجه بررسی به همان نسخه متصل است؛ تصمیم قدیمی به نسخه تازه منتقل نمی‌شود. گیرندگان سند خود با اشتراک دریافتی تفاوت دارند. هیچ اعلان، دعوت واقعی، انتشار یا دسترسی خارجی ایجاد نمی‌شود. تاریخچه کامل ممیزی، مقایسه diff و بازگردانی نسخه قبلی خارج از این مرحله‌اند.

محتوای متن، تصویر SVG و PDF کاملاً ساختگی است. PDF در صفحه سند با تصویر رندرشده صفحه اول و لینک فایل اصلی نمایش داده می‌شود. دارایی‌ها در `public/sample-content` قرار دارند؛ PDF با `scripts/create-sample-report.py` و reportlab تولید شده است. پوشه‌ها مسیر مستقل داخل مخزن دارند؛ شناسه نامعتبر با پیام فارسی مشخص می‌شود.

کاتالوگ در `/` شامل ۱۳ بخش و راهنمای ۲۲ قرارداد است. اجزای قابل استفاده مجدد در `components/ui` و قاب‌ها و داده‌های ساختگی در `components/design-system` قرار دارند. فونت IRANYekan محلی است؛ الزامات مجوز دارایی محصول حفظ شوند.

## بررسی و build

```sh
npm run tokens:check
npm run lint
npm run build
npm run start
```

تست‌های منطق فهرست و روابط داده (Node.js با پشتیبانی از TypeScript type stripping):

```sh
node --experimental-strip-types --test test/workspace-documents.test.mjs test/workspace-mutations.test.mjs test/workspace-collaboration.test.mjs
```

منبع توکن‌ها `lib/design-system/tokens.json` است. پس از تغییر آن `npm run tokens:generate` اجرا شود؛ build خروجی قدیمی را رد می‌کند.
